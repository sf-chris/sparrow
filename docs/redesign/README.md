# Redesign: before and after

Every page, captured from the real application against the same fresh fictional
fixture (six test titles, generated video, an owner named Chris, seeded progress
and one request). "Before" is `main` at `b85aac4`; "after" is the distilled
daylight redesign. Desktop is 1440px, phone 390px; captures are full-page, so the
phone tab bar appears where the viewport ended.

Regenerate with `tests/browser/tour.cjs` against `tests/browser/server.py`
(usage in the script header).
