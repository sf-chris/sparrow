# Live role evaluation, 23 November 2026 (issue #3, P2)

`tests/evals/run_live.py`: the 30 contract cases (`live-v1.json`) and a 12-case
unseen holdout (`live-holdout-v1.json`), 3 runs each, through the real agents,
runtime, tools and ledger. Only the model provider was live; TMDB, the indexer,
the download app and media were per-case fixtures. Models: `gpt-6-luna` for
Discovery, Fetch, Media and the Librarian; `gpt-6-sol` for the pick review,
escalation and the subtitle manager (the Anthropic key had no credit, so this
is not a Claude comparison). Judged on outcomes and every attempted tool call;
a blocked forbidden attempt still fails.

What the first run found, and the fixes (#33):

- **Librarian:** the cheap model wrote season keys like `"Season 3"`, which the
  `acquire` tool parsed with `int()` and rejected as out of scope. The tool now
  reads the forms models write, says what is eligible when a request can't be
  used, and `evidence` offers `request_missing`/`request_upgrades` as-is. Pass
  rate 42% → 100%. A first version of that offer nested by kind, which the model
  copied whole; it is flat now and a wrapped request is still read.
- **Media:** the cheap model moved a pack's unrequested episodes into the
  library in 2 of 3 runs (the inventory tool refused them). Its instructions now
  say only wanted episodes go into the library.
- **Subtitles:** after the fixes, one run retried the person's already set-aside
  upload; `use_source` now refuses set-aside sources.
- **Not yet fixed:** Discovery and the Librarian refuse to start without an
  Anthropic key even when their profile is an OpenAI model (the harness uses a
  placeholder key). One Media run in a re-run recorded a 40 MB fake "1080p" as
  unverified (3/3 and 6/6 in the other runs).

Limits: one model configuration; fixture worlds, not the installed server; no
device acceptance. Re-run with `SPARROW_RUN_LIVE_EVALS=1 .venv/bin/python
tests/evals/run_live.py --max-dollars 15` (and `SPARROW_PROFILES` or the model
variables for another configuration).
